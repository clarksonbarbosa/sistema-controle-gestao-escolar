# Cadastro de Alunos
O módulo de cadastro de alunos permitirá registrar e consultar informações dos estudantes.

## Funcionalidades
- Cadastrar aluno;
- Alterar dados do aluno;
- Consultar aluno;
- Organizar informações acadêmicas.

## Consulta e atualização
O sistema permitirá consultar os dados cadastrados e realizar a atualização das informações dos alunos, mantendo o histórico das alterações realizadas no projeto.
