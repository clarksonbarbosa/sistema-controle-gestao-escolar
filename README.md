# Sistema de Controle e Gestão Escolar

## Objetivo
O Sistema de Controle e Gestão Escolar tem como objetivo apoiar as atividades administrativas e acadêmicas de uma instituição de ensino, permitindo organizar informações de alunos, professores, turmas, disciplinas, notas e frequência.

## Principais funcionalidades
* Gerenciamento de usuários e permissões;
* Cadastro de alunos;
* Cadastro de professores;
* Cadastro de turmas e disciplinas;
* Registro de notas e frequência;
* Consulta de informações acadêmicas;
* Geração de relatórios;
* Geração de documentos em PDF;
* Apresentação de indicadores para apoio à gestão escolar.

## Tecnologias e ferramentas
* Git;
* GitHub;
* Markdown.

## Gerência de Configuração
O projeto utiliza o Git e o GitHub para controlar as versões dos arquivos, registrar alterações por meio de commits e manter um histórico das modificações realizadas durante o desenvolvimento.
